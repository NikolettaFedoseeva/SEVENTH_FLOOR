# Платформа Seventh Floor

Современная платформа для управления недвижимостью, построенная с использованием Vue 3, TypeScript и архитектурного подхода Feature-Sliced Design (FSD).

## Обзор проделанной работы (версия 1.0.0.1)

В рамках текущего этапа разработки был реализован широкий спектр функциональных возможностей и улучшений:

### 🏠 Управление недвижимостью

- **Мягкое удаление (Soft Delete)**: Реализована система безопасного удаления объектов через флаг `is_remove`. Администраторы могут восстанавливать удаленные объекты прямо из панели управления.
- **Динамическая форма создания**:
  - Поддержка различных рубрик: **Продажа**, **Аренда**, **Обмен**.
  - Гибкая валидация полей в зависимости от выбранного типа недвижимости (квартиры, дома, земля, коммерция).
  - Улучшенная логика для рубрики "Обмен", позволяющая сохранять объекты с минимальным набором обязательных данных.
- **Расширенная работа с медиа**:
  - Увеличен лимит загрузки фотографий до **30 штук** на один объект.
  - Добавлена поддержка загрузки видеофайлов и ссылок (Youtube/Vimeo) с предпросмотром в Lightbox.
  - Исправлена логика выбора главной фотографии (исключение дублирования в общем списке).

### 📧 Коммуникации и формы

- **Email-интеграция**: Настроен бекенд на базе `nodemailer` для автоматической отправки заявок из контактной формы на почту компании. Реализована отказоустойчивость SMTP-соединения.
- **Маски ввода**: Внедрена универсальная система масок для полей ввода. Поле "Телефон" теперь автоматически форматирует номер (например, `+373 (###) ###-##`), предотвращая ошибки ввода.

### 🎨 Интерфейс и UX

- **Валидация и индикация**:
  - Добавлены визуальные индикаторы (\*) для всех обязательных полей.
  - Реализован вывод подробных ошибок под каждым некорректно заполненным полем.
  - Добавлен глобальный алерт вверху формы при наличии ошибок валидации.
- **Улучшенная навигация**: Исправлена подсветка активных пунктов меню в хедере (использование `exact-active`), что обеспечивает корректное отображение текущего раздела.
- **Автоматизация**: Реализована полная очистка всех полей формы (включая медиа-файлы и состояние рубрик) после успешного создания объявления.

### 🛠 Технический стек и архитектура

- **Frontend**: Vue 3 (Composition API, `<script setup lang="ts">`), Pinia, Sass, FSD Architecture.
- **Backend**: Express, Node.js, MySQL, Multer (Media Upload), Nodemailer.
- **Архитектура**: Строгое соблюдение слоев FSD (shared, entities, features, widgets, pages) и использование Barrel-экспортов (`index.ts`).

## Установка и запуск

1. Установите зависимости в корне проекта и в папке `server`:
   ```bash
   npm install
   cd server && npm install
   ```
2. Настройте файлы `.env` (база данных, SMTP).
3. Запустите проект:
   - Фронтенд: `npm run dev`
   - Бекенд: `npm run start` (из папки server)

## ⚠️ Текущие сложности

- **Доставка почты (SMTP/DNS)**: На данный момент при отправке форм может возникать ошибка `550 Sender verify failed`.
  - _Причина_: Доменное имя `seventhfloor.md` требует завершения настройки DNS-записей (SPF, DKIM) или ожидания делегирования.
  - _Текущий статус_: Весь код на стороне приложения (Nodemailer, API-эндпоинты) полностью готов и протестирован. Как только домен будет корректно распознаваться почтовыми серверами, отправка заработает автоматически.

## 🚀 План развития (Roadmap)

В будущем проект можно улучшить в следующих направлениях:

1. **SEO Оптимизация**:
   - Автоматическая генерация `meta`-тегов для каждой страницы объекта (Title, Description, OpenGraph).
   - Генерация динамического `sitemap.xml`.
2. **Производительность**:
   - Внедрение серверной оптимизации изображений (конвертация в WebP "на лету").
   - Настройка ленивой загрузки (Lazy Loading) для медиа-контента в каталоге.
3. **Функциональность**:
   - **Личный кабинет пользователя**: Возможность отслеживать статус своих заявок.
   - **Сравнение объектов**: Добавление функции "Сравнить" по характеристикам.
   - **Мультиязычность (i18n)**: Поддержка румынского и английского языков.
4. **Тестирование**:
   - Покрытие Unit-тестами критически важной бизнес-логики (адаптеры данных, расчеты площадей).
   - E2E тесты для основного пути пользователя (поиск -> просмотр -> заявка).
5. **Безопасность**:
   - Настройка полноценного SSL-сертификата на основном сервере для перехода на HTTPS.
