# Платформа Seventh Floor

Современная платформа для управления недвижимостью, построенная с использованием Vue 3, TypeScript и архитектурного подхода Feature-Sliced Design (FSD).

## Обзор проделанной работы (версия 1.1.0)

В рамках текущего этапа разработки был реализован широкий спектр функциональных возможностей и улучшений:

### 🏠 Управление и отображение недвижимости

- **Детальная карточка объекта (Property Detail)**:
  - **Динамическая фильтрация характеристик**: Реализована логика отображения полей в зависимости от типа недвижимости (Квартиры, Дома, Коммерция, Гаражи, Земля). Исключены избыточные поля (например, «удобства» для гаражей или «парковка» для квартир).
  - **Расчет цены за м²**: Добавлен автоматический расчет и отображение цены за квадратный метр.
  - **Типы объявлений**: Внедрены наглядные бейджи для рубрик **Продажа**, **Аренда** и **Обмен**.
  - **Синхронизация с формой**: Унифицированы названия полей и их значения (например, «Есть смежные комнаты», «Источник отопления») для полной идентичности данных в админке и на сайте.
- **Интеллектуальная медиа-галерея**:
  - Исправлено дублирование изображений: Внедрена нормализация URL, которая исключает главное фото из списка дополнительных, независимо от формата пути.
  - Поддержка видео (Youtube/Vimeo) и до 30 фотографий на объект.
- **Мягкое удаление (Soft Delete)**: Система безопасного удаления через флаг `is_remove` с возможностью восстановления администратором.

### 📧 Коммуникации (Email)

- **Интеграция с Gmail SMTP**:
  - Настроена гарантированная доставка заявок через Gmail с использованием **App Passwords**.
  - Исправлена ошибка верификации отправителя (550 Sender verify failed).
  - **Отказоустойчивость**: Система теперь корректно обрабатывает сбои почтового сервера. Если письмо не ушло, сайт уведомляет об ошибке, что предотвращает потерю заявок.

### 🎨 Интерфейс и UX

- **Валидация форм**: Визуальные индикаторы обязательных полей (\*), детальные сообщения об ошибках и глобальные алерты.
- **Маски ввода**: Автоматическое форматирование номера телефона (`+373...`) для предотвращения ошибок пользователей.
- **Очистка данных**: Полный сброс состояния формы и медиа-файлов после успешного создания объявления.

### 🛠 Технический стек

- **Frontend**: Vue 3 (Composition API, `<script setup lang="ts">`), Pinia, Sass, FSD Architecture.
- **Backend**: Node.js + Express, MySQL, Multer (Media), Nodemailer (SMTP).
- **Конфигурация**: Оптимизирован `vue.config.js` для работы в любой локальной сети без привязки к жестким IP.

## Установка и запуск

1. **Зависимости**:
   ```bash
   npm install
   cd server && npm install
   ```
2. **Конфигурация**:
   - Настройте `server/.env` для базы данных и SMTP (используйте **Пароль приложения** для Gmail).
   - При необходимости настройте `.env` во фронтенде для `VUE_APP_API_URL`.
3. **Запуск**:
   - Сайт: `npm run dev` (порт 1000)
   - Сервер: `npm run start` (из папки `/server`, порт 3000)
